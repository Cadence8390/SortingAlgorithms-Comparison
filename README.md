# SortingAlgorithms-Comparison

A C++ program that implements and compares multiple sorting algorithms using a list of stock data. The program sorts the list in ascending and descending order and measures the execution time of each sorting operation.

# Features

- Implements selection sort, quick sort, and heap sort
- Supports ascending and descending sorting orders
- Randomizes the list before each sorting test
- Measures sorting execution time in microseconds
- Displays the list before and after sorting

# How to Run

1. Download the repository as a ZIP file.
2. Extract the downloaded folder.
3. Open the `.sln` file in Visual Studio.
4. Select Debug → Start Without Debugging to run the program.
